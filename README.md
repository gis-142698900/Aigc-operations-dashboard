# AIGC 互动大屏运营管理平台

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 构建生产版本，`npm test` 检查真实 CSV 数据的聚合与状态统计。

## 数据与交互

- 页面数据由 `public/data/` 中的 CSV 通过浏览器请求加载，并用 PapaParse 解析；更新 CSV 后无需修改代码，重新部署即可生效。
- 默认展示数据最后 14 天。日、自然周（周一开始）、自然月聚合；小时粒度禁用。月选择使用月份输入，周选择日期边界并按自然周汇总，边界周仅包含选定日期。
- 比率由总分子除以总分母计算，生成时长按请求数加权。日级 UV 跨日求和，遵循本次需求，不表示跨日去重人数。
- 上一周期为紧邻当前区间的等长天数；历史覆盖不足时不显示变化。比率变化用 pp，其他指标用百分比。
- 审核、在线率、异常为当前快照，只随点位筛选。快照更新时间取设备最后心跳最大值。
- 更多菜单导出 CSV，包含当前粒度、日期范围和点位条件。表格八种排序均为降序。
- 其他三个导航入口为占位页面。
